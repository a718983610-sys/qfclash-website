# QFClash 网页版 UI 重设设计要点（2026-10-24）

用户口径：现界面太土，按大厂社区产品的做法重设；品牌仍为 QFClash 蓝，禁止照抄
参考站的商标、图标与素材，仅学习布局、层级与质感手法。

## 参考对象与取法（知乎 / 百度贴吧 / 小米社区）

- 知乎：浅灰底色（#f6f6f6）承托白色内容卡片；卡片靠 1px 浅边与极轻阴影分层，
  不用重描边；标题粗黑、正文深灰、元信息浅灰三级文字；品牌蓝只用在主操作与
  选中态，次级操作一律浅灰文字按钮；信息流条目以「作者行—标题—摘要—操作行」
  的固定层级排布，统计数放在操作行、小号灰字。
- 百度贴吧：论坛场景的信息组织——板块以横向标签切换，帖子列表一行一帖：
  标题为主、作者与时间次之、回复/浏览数右对齐弱化；板块头部有社区信息卡
  （名称、简介、成员数、帖子数）与醒目的加入/发帖按钮。
- 小米社区：大圆角卡片（12px 以上）、宽留白、顶部栏干净（白底、细分割线），
  类目标签为胶囊选中态（浅色底＋品牌色字），帖子卡间距舒展（14–16px），
  图片与头像圆角统一，整体克制、少色块轰炸。

## 落到本产品的设计系统（assets/app.css）

- 色板：底色 --bg #f3f5f9；卡片白；主文字 #17202e；次级 #5d6878；弱化 #97a1b1；
  分割线 #e4e9f0（更细更浅）；品牌蓝 --brand #2563eb，仅主按钮、链接、选中态；
  选中浅底 --brand-soft #eaf1fe；危险/成功/警告维持语义色但降低饱和。
- 形状：卡片圆角 14px＋轻阴影（0 1px 3px rgba(23,32,60,.05)）；按钮圆角 10px；
  胶囊 999px；头像圆形；输入框圆角 10px、聚焦时品牌色描边＋浅蓝光晕。
- 字阶：页面标题 20px/700；卡片标题 16px/600；正文 15px/1.65；次级 13.5px；
  元信息 12.5px 弱化色。列表条目间距拉开（上下 12–14px），分割线 hairline。
- 顶栏：白底毛玻璃感（半透明白＋backdrop blur）、品牌块为蓝底圆角方块「QF」字标
  ＋名称；抽屉导航条目圆角块、选中浅蓝底蓝字，条目间距 4px。
- 论坛：板块胶囊切换（选中浅蓝底）；帖子行=作者行（小头像＋昵称＋时间）＋标题
  （16px 粗）＋一行摘要/统计（赞/回复/浏览小号灰字右组）；营地做成卡片网格
  （名称＋简介＋成员/帖子数＋加入按钮）；详情页正文行高 1.75、操作行图标化数字。
- 好友/聊天：≥960px 双栏（左 320px 列表栏：搜索、申请、好友、会话；右聊天区），
  左栏条目选中浅蓝底；气泡圆角 16px——对方白底描边、自己品牌蓝底白字，最大宽
  72%，时间等系统信息居中弱化；<960px 单栏微信式：列表页与聊天页分页呈现，
  聊天页顶部带返回。
- 客服：与聊天同一视觉语言（同气泡/同输入栏），机器人身份行用品牌小头像块，
  快捷问题为胶囊；提示条改浅蓝信息条，不再用土黄大块。
- 按钮层级：primary 实心蓝仅给页面主动作；ghost 白底细边给次级；列表内小动作
  用文字按钮（.mini-btn）；危险动作红字/红底仅在确认弹窗。
- 动效：hover 背景 #f4f7fd、过渡 .15s；抽屉 .22s 滑出维持；卡片不做悬浮位移
  （社区产品以稳为主）。

## v2 精修（2026-10-24 第二轮）：对标小米社区的「惊艳感」

用户评第一轮「没有小米论坛设计惊艳」，本轮在 v1 功能与结构契约（类名/id/
事件绑定）全保留的前提下只做视觉精修。

### 小米社区（xiaomi.cn）研学要点（实抓首页文本层＋其公开产品既定风格）

- 首页第一屏是**大图横幅卡**：整幅活动封面＋图上标题＋时间/参与数据，
  不是文字列表开局；信息层级靠「大图先行」建立档次。
- 信息流是**独立卡片流**（不是分隔线列表）：每帖一张卡，卡内顺序为作者行
  （头像＋昵称＋设备/圈子标签＋时间）→ 标题 → 摘要 → 底部数据行（点赞/
  评论图标＋数字），卡间距约 16px、圆角 16–20px、阴影柔和多层。
- 版块/圈子入口是**彩色圆角方形图标块＋名称＋副文案**的网格卡，不是文字
  胶囊平铺；图标块各有专属色，选中/悬停有明确状态。
- 精选内容用**更大的头图卡**突出（封面带＋大标题），与普通卡拉开层级。
- 数据点缀克制而精致：徽章、热度标签、小号图标数字；大量留白与字阶
  （标题 17–19 粗体、正文 15、元信息 12–13 浅灰）撑起质感。
- 抓取说明：小米社区站点为 JS 空壳＋反抓，文本层只拿到内容结构（横幅/
  卡片流/圈子/公告的组织方式，与上一致），视觉参数按其公开产品既定风格
  提炼，未使用其商标、图标素材与橙色品牌色。

### v2 设计系统（全站一语言，令牌以 app.css :root 为准）

- 色板：底 #eef1f6；卡白；主文字 #161e2c；次级 #5b6779；弱化 #98a2b3；
  分割线 #e2e8f1／#e9eef5；品牌蓝 #2563eb（深 #1d4ed8），主按钮与 hero
  用渐变 --brand-grad（#3b82f6→#2563eb→#1e40af）；选中浅底 #eaf1fe；
  语义色降饱和（危险 #c62f2f／成功 #177245／警告 #96660a）；热度点缀
  暖红 #e5484d（仅「热门」标签与未读徽章）。
- 字阶：页面大标题 22/800；hero 标题 27/800（移动 23）；卡片标题
  17.5/700；帖子标题 17/650；正文 15/1.6（详情正文行高 1.75）；次级
  13.5；元信息 12.5 弱化色。统计数字一律图标＋数字成对出现。
- 间距：页面边距 18（移动 12）；卡片内边距 22（移动 17）；卡间距 16；
  卡片流内间距 12–14；列表行上下 13。
- 圆角：卡 16；大卡（hero/资料头图/feature）20；按钮 11；胶囊 999；
  图标块 13–14；头像全圆。
- 阴影：三档 --shadow（静置）／--shadow-hover（悬停）／--shadow-lift
  （hero 与浮层）；主按钮带蓝色投影，禁止无阴影硬边大色块。
- 动效：页面块入场 fadeUp .28s ease（仅挂载播一次）；悬停抬升 1–2px
  ＋阴影加深（.18s）；按压 scale .98；抽屉 .24s cubic-bezier；骨架
  shimmer 1.3s 线性循环；过渡基准 .15s。
- 组件规范：板块/导航图标块＝专属色渐变方块＋白色线性 SVG 图标（四
  板块：综合=气泡蓝、求助=问号青、建议=笔紫、公告=喇叭靛）；帖子封面
  块＝板块渐变＋白色大图标（栏目封面占位，帖子无图数据不伪造配图）；
  热门标签＝点赞 ≥ 50 数据驱动显示。

### v2 信息架构与交互变更清单（相对 v1）

1. 顶栏重构：桌面端加主导航胶囊（首页/论坛/好友/积分/智能客服，与
   路由高亮同步）；右上加搜索按钮；顶栏滚动时加深阴影。
2. 搜索层：点顶栏搜索打开浮层——好友精确搜索（与好友页同一接口，
   结果可直接发申请）＋四宫格快捷入口；无服务端支撑的帖子搜索不做
   假入口。Esc/点遮罩关闭。
3. 移动端底部主导航（<960px）：首页/论坛/发帖（凸起主按钮）/好友/
   我的五格，与路由高亮同步；聊天页自动隐藏（防遮输入区）；内容区
   底部留白防遮挡。
4. 首页信息流化：欢迎区改为 hero；新增「逛板块」卡片墙（点卡直达
   论坛对应板块）；新增「最新帖子」流（公开接口前 6 条，与论坛同一
   卡片组件）；功能导航保留并加图标块。
5. 论坛首页结构：身份卡改为 hero；板块切换由文字胶囊改为图标卡
   网格（data-board 契约不变）；帖子流改独立卡片流；新增「加载
   更多」分页（offset 递进、不足一页自动收起）；新增发帖 FAB
   （桌面右下/移动端在底部导航上方），点按打开发帖框并滚动定位。
6. 底部导航「发帖」钮：任意页点按直达论坛并自动打开发帖框。
7. 页签条（ftabs）改实色渐变选中态并吸顶（sticky）。
8. 个人页/他人主页：首卡改为资料头图（封面条＋头像悬挂＋数据行）。
9. 加载态：论坛体、外站精选、会话列表、首页板块墙/帖子流接入骨架
   屏，替换纯文字「正在加载…」；空状态统一为图标圆块＋主/次文案。
10. 详情页：标题加大、作者行保留、数据行图标化；回复沿用卡片行。

### 落到 QF 的 v2 规范（品牌仍为 QF 蓝）

- 令牌：卡片圆角 16px、大卡 20px；阴影三档（rest/hover/lift）；底色
  微调 #eef1f6；页面块入场动画 fadeUp .28s（仅挂载播一次）；主按钮渐变蓝
  ＋按压回弹；选中态一律「浅蓝底＋品牌描边」双信号。
- 论坛头图 hero：品牌蓝渐变横幅（深蓝→亮蓝＋径向光斑＋大字标水印），
  身份行融入 hero（头像光环＋昵称大字＋账户 ID 弱化），未登录版给标语＋
  登录主按钮。id `forumAvatar` 与 showAvatar 契约不变。
- 板块卡网格：每板块一张卡（线性 SVG 图标块，板块专属柔和色＋名称＋
  一句产品文案），选中态描边高亮；仍用 `data-board` 契约与原事件绑定。
- 帖子卡：作者行（头像 40＋昵称 15/600＋时间·板块第二行弱化）→ 标题
  17px → 摘要 2 行 → 数据行（内联 SVG 图标＋数字）；右侧**板块封面块**
  （板块渐变＋白色大图标）——帖子本身无配图数据，这是栏目封面占位，
  不伪造文章配图；点赞 ≥ 50 显示「热门」暖红标签（数据驱动）。
- 外站精选：首条 feature 大卡（平台封面带＋19px 标题＋3 行摘要），
  其余标准卡行（平台色小封面块）。
- 营地卡：顶部封面带（渐变＋营地名首字大字）＋内容区，hover 抬升。
- 个人页/他人主页：资料头图（渐变封面条＋头像悬挂＋昵称大字＋数据行），
  `meAvatar`/`fuAvatar` 契约不变。首页同步加 hero 与导航图标块。
- 好友/聊天：列表项选中态左蓝条＋头像细光环；气泡阴影柔化、己方渐变蓝。
- 状态件：空状态组件（大号浅色圆块＋字形＋主/次文案）；骨架屏 shimmer
  （论坛体、外站精选、会话列表三处接入，替换纯文字「正在加载…」）。

## ui3 帖子卡交互（2026-10-24 第三轮，用户亲令）

- 整卡进详情：`postItemHtml` 渲染的帖子卡（论坛流/首页最新帖子/营地帖子/
  个人主页/数据分析共用同一组件）加 `data-post` 标记，document 级事件委托
  （`bindPostCards`，只挂一次）实现任意位置点击进详情。
- 卡内拦截：点赞钮、评论钮、评论区、板块标签（`data-card-board`，点按切到
  对应板块）、作者头像（去个人主页）、昵称/标题链接、其余按钮与表单控件
  均不触发整卡跳转；标题原有 `<a>` 保留（键盘可达性）。
- 列表内点赞：`POST /forum/posts/:id/like {liked}` 幂等置位，乐观更新＋
  失败回滚，回包 `{likeCount, liked}` 为权威值；已赞态 `.ps-act.liked`
  暖红实心爱心。
- 列表内评论：点评论钮在卡内展开轻量评论框（首次点击才建 DOM），提交
  `POST /forum/posts/:id/replies`；published 才即时 +1（与服务端「回复数
  只统计已发布」口径一致），pending 显示服务端待审文案、rejected 显示
  驳回原因，均不计数；未登录显示登录引导（与详情页口径一致）。
- 外站精选卡（站内无点赞/评论接口）：标准卡整卡点击打开原文（新标签），
  与首条 feature 大卡（整卡为链接）行为一致。

## 三端与范围口径

- 账号类功能三端同步：好友/聊天/论坛/营地/积分/客服/安全中心/意见反馈网页全有。
- 网页做不到的不上网页：连接 VPN、节点/订阅管理、客户端设置类——首页与顶栏
  明确引导用客户端，不在网页做假入口。
- 智能客服问答逻辑（三层转人工）由服务端线负责，网页只做呈现与既有接口对接。
