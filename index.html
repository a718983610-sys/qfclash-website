产品介绍

QFClash 是一款基于开源项目 FlClash 与 mihomo 内核二次开发的网络代理工具软件，提供 Android 与 Windows 两个平台版本。软件界面布局清晰，全部功能均以简体中文呈现，复杂功能旁设有说明图标，点开即可查看详细介绍与使用示例。

QFClash 仅提供工具软件本身，不运营服务器，不提供、不销售任何节点、线路、流量或订阅。用户可将自行取得的订阅导入软件后使用，软件支持节点手动选择、订阅管理、连通性测试与流量统计等完整功能。

积分规则

登录用户在使用 QFClash 期间可累计积分，积分可用于兑换订阅好礼。现行规则公示如下：

  • 积分按有效使用时长累计：连接使用每满 3 小时得 1 分，未满 3 小时的部分按分钟累计不清零，进度在应用内随时可见。
  • 积分在 Android 与 Windows 双平台互通，同一账号共用一个积分账户；同一时段在两台设备同时使用，仅按一份时长计算。
  • 每日积分获取上限为 8 分。
  • 兑换标准：1000 分可兑换魔戒订阅 19.9 元档；1600 分可兑换魔戒订阅 29.9 元档。商品以应用内实际上架为准。
  • 兑换前需二次确认；奖品经人工审核后发放，兑换记录可在应用内「我的兑换」中查看。
  • 访客模式下不累计积分。访客每日可免费使用 2 小时，登录后不限时长。
  • 积分规则如有调整，将在应用内与本页面提前公示。
