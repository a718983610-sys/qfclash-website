产品介绍

QFClash 是一款基于开源项目 FlClash 与 mihomo 内核二次开发的网络代理工具软件，提供 Android 与 Windows 两个平台版本。软件界面布局清晰，全部功能均以简体中文呈现。

QFClash 仅提供工具软件本身，不运营服务器，不提供、不销售任何节点、线路、流量或订阅。用户可将自行取得的订阅导入软件后使用，软件支持节点手动选择、订阅管理、连通性测试与流量统计等完整功能。

QFClash 在 Android 与 Windows 上提供一致的核心体验：同一订阅、同一账号、同一积分账户，跨设备使用无缝衔接。界面遵循各平台的操作习惯，常用功能一步可达，力求让每一位用户都能轻松上手。

功能亮点

以下为 QFClash 的主要功能介绍，各功能在 Android 与 Windows 双平台均可使用。

📥

订阅管理

支持通过订阅链接导入，也可导入本地配置文件；可保存多个订阅并一键更新。订阅的流量用量与到期时间在界面内清晰展示，方便随时掌握使用情况。

🎯

节点选择与测速

节点按订阅分组展示，可手动选择任意节点连接；内置连通性测试与延迟测速，节点状态直观呈现。设置中可开启「自动选最快节点」，连接时自动挑选延迟最低的节点。

🧭

规则与全局模式

提供规则模式、全局模式与直连模式：规则模式依据配置规则智能分流；全局模式让全部流量经由代理节点；直连模式则暂停代理。三种模式可按需一键切换。

📱💻

双平台一致体验

Android 与 Windows 双平台同步发布，界面布局兼顾各平台的操作习惯。同一账号、同一订阅、同一积分账户，跨设备使用无缝衔接。

👤

账号与积分

登录用户不受限制：不限使用时长，全部功能完整开放，并可按规则累计积分、兑换美元奖励（规则见下方积分规则）；访客模式每日可免费使用 2 小时，时长与功能均受限制。账号提供设备管理与远程下线功能，登录安全可控。

🌐

全中文与功能说明

界面文案全部为简体中文，功能说明清晰易懂，新手也能快速上手。

🎨

双主题设计

提供浅色与深色两套主题。深色主题采用深灰配色而非纯黑，白天与夜间使用都舒适；主题可手动切换，也可跟随系统设置。

积分规则

登录用户在使用 QFClash 期间可累计积分，积分可用于兑换美元奖励。现行规则公示如下：

  • 积分按有效使用时长累计：连接使用每满 3 小时得 1 分，未满 3 小时的部分按分钟累计不清零，进度在应用内随时可见。
  • 积分在 Android 与 Windows 双平台互通，同一账号共用一个积分账户；同一时段在两台设备同时使用，仅按一份时长计算。
  • 每日积分获取上限为 8 分；每台设备每日最多获得 8 分，账号上限与设备上限同时适用，任一达到上限即当日不再计分。
  • 兑换标准：1000 分可兑换 $5 美元奖励；1600 分可兑换 $10 美元奖励。商品以应用内实际上架为准。
  • 兑换前需二次确认；奖品经人工审核后发放，兑换记录可在应用内「我的兑换」中查看。
  • 登录状态不受限制：登录用户不限使用时长，全部功能完整开放，并可累计积分；访客每日可免费使用 2 小时，且不累计积分。
  • 积分规则如有调整，将在应用内与本页面提前公示。
  • 积分累计不受所在地区影响，福利兑换面向全球用户开放。
  • 论坛每日积分：在官方论坛每天发布 1 条帖子或 1 条评论可得 1 分，每天限 1 次；该积分单独计算，不占用每日 8 分的连接积分上限。灌水、刷分内容被驳回或删除的，当日积分取消。
