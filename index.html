产品介绍

QFClash 是一款基于开源项目 FlClash 与 mihomo 内核二次开发的网络代理工具软件，提供 Android 与 Windows 两个平台版本。软件界面布局清晰，全部功能均以简体中文呈现，复杂功能旁设有说明图标，点开即可查看详细介绍与使用示例。

QFClash 仅提供工具软件本身，不运营服务器，不提供、不销售任何节点、线路、流量或订阅。用户可将自行取得的订阅导入软件后使用，软件支持节点手动选择、订阅管理、连通性测试与流量统计等完整功能。

QFClash 在 Android 与 Windows 上提供一致的核心体验：同一订阅、同一账号、同一积分账户，跨设备使用无缝衔接。界面遵循各平台的操作习惯，常用功能一步可达，力求让每一位用户都能轻松上手。

功能亮点

以下为 QFClash 的主要功能介绍，各功能在 Android 与 Windows 双平台均可使用。

📥

订阅管理

支持通过订阅链接导入，也可导入本地配置文件；可保存多个订阅并一键更新。订阅的流量用量与到期时间在界面内清晰展示，方便随时掌握使用情况。

🎯

节点选择与测速

节点按订阅分组展示，可手动选择任意节点连接；内置连通性测试与延迟测速，节点状态直观呈现。设置中可开启「自动选最快节点」，连接时自动挑选延迟最低的节点。

🧭

规则与全局模式

提供规则模式、全局模式与直连模式：规则模式依据配置规则智能分流；全局模式让全部流量经由代理节点；直连模式则暂停代理。三种模式可按需一键切换。

📱💻

双平台一致体验

Android 与 Windows 双平台同步发布，界面布局兼顾各平台的操作习惯。同一账号、同一订阅、同一积分账户，跨设备使用无缝衔接。

👤

账号与积分

登录用户不受限制：不限使用时长，全部功能完整开放，并可按规则累计积分、兑换订阅好礼（规则见下方积分规则）；访客模式每日可免费使用 2 小时，时长与功能均受限制。账号提供设备管理与远程下线功能，登录安全可控。

🌐

全中文与功能说明

界面文案全部为简体中文。复杂功能旁设有说明图标，点开即可查看该功能的用途、适用场景以及开启与关闭的区别，新手也能快速上手。

🎨

双主题设计

提供浅色与深色两套主题。深色主题采用深灰配色而非纯黑，白天与夜间使用都舒适；主题可手动切换，也可跟随系统设置。

积分规则
